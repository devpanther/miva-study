Electromagnetic induction is a phenomenon in physics
where an electric current is generated in a conductor when it
is exposed to a changing magnetic ﬁeld. This process was
ﬁrst discovered by Michael Faraday in the early 19th century
and is one of the fundamental principles behind the
operation of many electrical devices.
General Physics II




When a conductor, such as a wire, is placed in a
magnetic ﬁeld and the magnetic ﬁeld changes, an
electric current is induced in the conductor. This can
occur through various means, such as moving the
conductor relative to the magnetic ﬁeld or changing
the strength of the magnetic ﬁeld.

The induced current ﬂows in such a way that it creates
its own magnetic ﬁeld, which opposes the change in
the original magnetic ﬁeld. This phenomenon is known
as Lenz’s law.
 General Physics II




The process of electromagnetic induction forms the basis for
many practical applications. One of the most common
examples is the operation of electrical generators. In a
generator, a coil of wire is rotated within a magnetic ﬁeld,
causing an induced current to ﬂow through the wire. This
current can then be used to power electrical devices.
General Physics II



The magnetic ﬁeld strength of a coil is determined by
the ampere turns of the coil. An increase in the
number of turns results in an increase in the magnetic
ﬁeld strength. Moving a magnet “in” and “out” of the
coil would induce a current in the coil. This is due to
the movement of the magnetic ﬂux caused by the
magnetic ﬁeld.
General Physics II

    In Summary

This week, you learned about definite integrals and their applications in area calculation. Definite integrals
enable us to determine the exact area bounded by functions and the x-axis. The key concept is that the
integral represents the signed area enclosed between the curve and the x-axis from a starting point ‘a’
to an endpoint ‘b’. We achieved this by breaking down the region into infinitesimally small vertical strips,
meticulously calculating each strip’s area, and then summing them up. This process provides the net area
between the curve and the x-axis. You also learned the concept of Riemann sums, which allow us to calculate
the area beneath complex curves. Additionally, you learned how definite integrals can be applied to find the
area between two curves and dealt with examples where the curves intersect or have intricate features.
Definite integrals prove to be a powerful tool for precisely determining areas between curves, regardless
of their complexity.

Application Programming Interface (API)
An Application Programming Interface (API) is a set of rules, protocols, and tools that allows
dierent software applications to communicate with each other.
APIs deﬁne the methods and data formats that developers can use to request and
exchange information or perform actions between systems.
APIs are used to enable the integration of dierent software components, services, or
platforms.
APIs have become the building blocks of modern software development, allowing dierent
applications and systems to communicate and share data seamlessly.
     Introduction to Web Technologies


APIs: Importance
APIs play a crucial role in modern software development for reasons such as;
Interoperability: They facilitate interoperability between dierent software systems,
enabling them to work together and share data.
Modularity: APIs allow developers to build modular and reusable components, reducing
development time and eort.
Scalability: APIs enable applications to scale by leveraging external services and data
sources.
Ecosystem Expansion: They encourage the growth of software ecosystems by enabling
third-party developers to create add-ons and extensions.
Front-End and Back-End Separation: APIs enable a clear separation between the
front-end (user interface) and back-end (server) of an application.
     Introduction to Web Technologies


API Development and Integration: Key Terms
Endpoint: An API endpoint is a speciﬁc URL or URI (Uniform Resource Identiﬁer) that
represents a resource or service provided by an API. Endpoints are used to send requests and
receive responses.
HTTP Methods: HTTP (Hypertext Transfer Protocol) methods deﬁne the actions that can be
performed on resources. Common methods include GET (retrieve data), POST (create data),
PUT (update data), and DELETE (remove data).
Request: A request is made by a client (e.g., a web browser or application) to an API endpoint
to perform an action, such as retrieving data or submiing data for processing.
Response: A response is the result returned by the API after processing a request. It
includes status information, data, and headers.
Authentication: Authentication is the process of verifying the identity of a client or user
before granting access to an API. It can be done using API keys, tokens, or other methods.
Rate Limiting: Rate limiting restricts the number of API requests that can be made within
a speciﬁed time frame to prevent abuse and ensure fair usage.
