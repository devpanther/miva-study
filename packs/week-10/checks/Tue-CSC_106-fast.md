# Tuesday — CSC_106 fast-hour check

*Backend development: server-side languages, stacks, DBMS types and API methods.*
*Five questions, straight after the fast hour. Recall only. Score out of 5.*

**1.** Which language is named for event-driven, non-blocking I/O?
A. Node.js
B. Python
C. Ruby
D. Java

**2.** Which HTTP method's named job is creating data?
A. GET
B. PUT
C. POST
D. DELETE

**3.** Docker containerises an application. What orchestrates the containers?
A. Helm
B. Kubernetes
C. Prometheus
D. Grafana

**4.** Which named DBMS is an in-memory key-value store used for caching?
A. MongoDB
B. PostgreSQL
C. Oracle Database
D. Redis

**5.** What does the C in ACID stand for?
A. Concurrency
B. Consistency
C. Caching
D. Compatibility

## Answers

**1. A** — Node.js is the deck's answer for real-time stock prices, because event-driven non-blocking I/O handles many concurrent connections. Python is named for versatility, Ruby for elegant syntax, Java for reliability.

**2. C** — POST creates a new resource; PUT updates an existing one. GET retrieves and changes nothing, and DELETE removes.

**3. B** — Kubernetes orchestrates containers in the microservices environment. Helm packages Kubernetes apps, and Prometheus and Grafana do the monitoring.

**4. D** — Redis is the in-memory NoSQL key-value store for caching, real-time analytics and message brokering. MongoDB is the document-oriented NoSQL one; PostgreSQL and Oracle are relational.

**5. B** — ACID is Atomicity, Consistency, Isolation, Durability, a guarantee about transactions surviving failures. Concurrency and caching are performance ideas, not ACID letters.
