# Tuesday — CSC_106 fast-hour check

*Future trends: WebAssembly, serverless, machine learning types, WCAG principles and PWAs.*
*Five questions, straight after the fast hour. Recall only. Score out of 5.*

**1.** WebAssembly is best described as what?
A. A JavaScript framework
B. A browser extension standard
C. A binary instruction format for browsers
D. A cloud hosting provider

**2.** Which serverless key concept means no state is kept between invocations?
A. Stateless
B. Event-Driven
C. Functions as a Service
D. Cold start

**3.** Clustering customers into market segments is the deck's example of what?
A. Supervised learning
B. Computer vision
C. Natural language processing
D. Unsupervised learning

**4.** Alt text for screen readers illustrates which WCAG principle?
A. Operable
B. Perceivable
C. Understandable
D. Robust

**5.** Which technology gives progressive web apps offline access and push notifications?
A. Responsive design
B. Progressive enhancement
C. Screen readers
D. Service workers

## Answers

**1. C** — Wasm is a binary format the browser executes directly at near-native speed, compiled from C++, Rust or TypeScript. It complements JavaScript, whose performance limits it exists to fix, rather than replacing it.

**2. A** — Stateless means nothing persists between invocations. Event-driven is what triggers a function, FaaS is what runs, and a cold start is one of the two named challenges alongside vendor lock-in.

**3. D** — Clustering uses unlabelled data to find groupings, so it is always unsupervised. Supervised learning uses labelled data, illustrated by the spam filter; computer vision is facial recognition and NLP is the chatbot.

**4. B** — Perceivable means content is presented so all users can perceive it. Operable is keyboard and voice navigation, Understandable is plain language, and Robust is semantic HTML working with future technologies.

**5. D** — Service workers deliver offline access, resource caching and push notifications. Responsive design adapts to screen size, progressive enhancement is the build philosophy, and screen readers are an accessibility tool.
