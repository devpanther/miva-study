# Thursday — MTH_102 nightly check

*Graphical limit problems worked end to end: piecewise functions, one-sided limits at a joint, classifying the break, signed infinite limits at a vertical asymptote, and limits at infinity read off the curve.*
*Sit cold, notes closed, 8 minutes. Score out of 6.*

**1.** f(x) = x² for x < 1; f(1) = 4; f(x) = 3x − 2 for x > 1. Which statement is correct?
a) lim_{x→1} f(x) does not exist, because the value f(1) = 4 disagrees with the height both branches approach
b) lim_{x→1} f(x) = 1, and f has a removable discontinuity at 1: the branches both reach height 1, the filled dot sits at (1, 4), and redefining f(1) := 1 makes f continuous
c) lim_{x→1} f(x) = 4, since the limit at a point where the function is defined is the value the function takes there
d) lim_{x→1} f(x) does not exist, and the break is a jump discontinuity, since three different rules are used and the graph is cut into three pieces at x = 1

**2.** f(x) = 5 − x for x ≤ 2; f(x) = x² for x > 2. Which statement is correct?
a) lim_{x→2} f(x) = 3, because f(2) = 3 and the left branch agrees with it, so the limit takes the value both of them share
b) lim_{x→2} f(x) does not exist: the left limit is 3 and the right limit is 4, so f has a jump discontinuity at 2; f is continuous from the left there but not continuous at 2
c) lim_{x→2} f(x) = 4, because as x approaches 2 the rule that governs the immediate future of the graph is the right-hand piece x², and it is the piece the curve moves into
d) lim_{x→2} f(x) does not exist, but the discontinuity is removable, since the gap is only 1 unit high and can be closed by redefining f(2) := 3.5

**3.** f(x) = (2 − x)/(x − 3). Describe the graph near x = 3.
a) lim_{x→3⁻} f(x) = +∞ and lim_{x→3⁺} f(x) = −∞, so the two-sided limit does not exist; x = 3 is a vertical asymptote, with the left branch climbing it and the right branch plunging
b) lim_{x→3⁻} f(x) = −∞ and lim_{x→3⁺} f(x) = +∞, so the two-sided limit does not exist; x = 3 is a vertical asymptote, with the left branch plunging and the right branch climbing
c) lim_{x→3} f(x) = −∞ on both sides, since the numerator tends to −1 and a negative number over a vanishing denominator must run to −∞
d) Substitution gives −1/0, an indeterminate form, so the factor (x − 3) cancels and the graph has a hole at x = 3 rather than an asymptote

**4.** f(x) = 2x/(x² + 1). Which statement about its asymptotes is correct?
a) y = 0 is a horizontal asymptote at both ends, and the graph crosses it at (0, 0) — a horizontal asymptote constrains only the behaviour as x → ±∞
b) y = 0 cannot be an asymptote, because the graph meets the x-axis at the origin and an asymptote is a line the curve approaches without ever touching
c) x = 1 and x = −1 are vertical asymptotes, since the denominator x² + 1 vanishes at those two values
d) y = 2 is the horizontal asymptote, being the ratio of the leading coefficients of numerator and denominator

**5. (explain why)** Take f(x) = (x² − 9)/(x − 3) for x ≠ 3, with f(3) = 2; and g(x) = (x² − 9)/(x − 3) for x < 3, with g(x) = 2x for x ≥ 3. For **each** function give lim_{x→3⁻}, lim_{x→3⁺}, lim_{x→3} and the value at 3; describe the graph near x = 3 including the position of every open circle and filled dot; say whether it is continuous at 3; and where it is not, name the discontinuity and state the repair, or say why no repair exists.

**6. (explain why)** Compare g(x) = 1/(x − 2) with h(x) = 1/(x − 2)² near x = 2. Give all four one-sided limits, describe both graphs on each side of the asymptote, and explain precisely why we are willing to write lim_{x→2} h(x) = +∞ but refuse to write any equation at all for lim_{x→2} g(x) — and why, despite that difference, **neither** limit exists and **neither** discontinuity is removable.

---

## Answers

**1. b** — *At a joint of a piecewise function, evaluate each one-sided limit from the rule that governs that side, and read the value from the rule that governs the point itself; the three answers are independent.* For x < 1 the rule is x², so lim_{x→1⁻} f = 1² = 1; for x > 1 the rule is 3x − 2, so lim_{x→1⁺} f = 3 − 2 = 1. Equal and finite, so lim_{x→1} f(x) = 1. The middle rule gives f(1) = 4. Graphically: a parabola arriving at an open circle at (1, 1), a line leaving from an open circle at (1, 1), and a stray filled dot at (1, 4). Conditions (i) and (ii) hold, (iii) fails — a **removable** discontinuity, repaired by moving the dot to (1, 1). (a) treats a mismatch between limit and value as killing the limit; the limit never looks at x = 1. (c) is the substitution reflex, valid only where continuity has already been established — which is exactly what fails here. (d) counts rules instead of comparing one-sided limits; a jump needs the two branch heights to **differ**, and here they are both 1.

**2. b** — *A jump is diagnosed by unequal finite one-sided limits, and the value f(c) then decides which side, if either, f is continuous from.* Left rule 5 − x gives lim_{x→2⁻} f = 3; right rule x² gives lim_{x→2⁺} f = 4. Both finite, unequal, so the two-sided limit **does not exist** and the break is a **jump** of size 1. Because "≤" puts x = 2 in the left piece, f(2) = 3 = lim_{x→2⁻} f, so f is continuous **from the left** at 2 — a genuine property, but not continuity, which needs the full two-sided limit. Graphically: falling line ending in a filled dot at (2, 3); parabola starting from an open circle at (2, 4). (a) is the sharpest distractor: it is true that f(2) = 3 and that the left branch agrees, but a two-sided limit cannot be certified from one side plus the function value — the right branch heads somewhere else. (c) invents a direction of travel; a limit as x → 2 approaches from **both** sides at once and neither piece has priority. (d) misuses "removable": removable means the branches already agree and one point is misplaced; no single value of f(2) can sit at both height 3 and height 4, so a jump is never repairable — and 3.5 is a height the function never approaches from either side.

**3. a** — *At a vertical asymptote the magnitude comes from k/0 and the **sign** comes from testing the denominator on each side, then combining it with the sign of the numerator.* Near x = 3 the numerator tends to 2 − 3 = **−1**, a fixed negative number, so no cancellation is possible. For x slightly less than 3, x − 3 is a small **negative** number, and negative divided by negative is positive: the quotient is large and positive, so lim_{x→3⁻} f = **+∞** and the left branch climbs the asymptote. For x slightly more than 3, x − 3 is small **positive**, and negative over positive is negative: lim_{x→3⁺} f = **−∞**, and the right branch plunges. The signs disagree, so the two-sided limit does not exist and cannot be written as ±∞ either. (b) is the same reasoning with one sign slip — the error of remembering "left goes down, right goes up" from 1/x without checking that this numerator is negative; it is the option most students land on. (c) tracks the numerator's sign but ignores that the denominator changes sign across 3, which is the whole point of testing both sides. (d) misreads −1/0 as indeterminate; only 0/0 is, and since the numerator is non-zero at 3 the factor (x − 3) cannot cancel, so a hole is impossible.

**4. a** — *Asymptotes are limit statements: horizontal ones describe x → ±∞ only, so they say nothing about what the curve does at finite x.* Dividing by x² gives (2/x)/(1 + 1/x²) → 0 at both ends, so **y = 0 is a horizontal asymptote as x → +∞ and as x → −∞**. Setting f(x) = 0 gives x = 0, so the curve **crosses** its asymptote at the origin, then rises to a peak at (1, 1) before flattening back toward the axis; the picture is mirrored below the axis for x < 0. Since x² + 1 ≥ 1 > 0 for all real x, the denominator never vanishes: there is no vertical asymptote and f is continuous on the whole of ℝ. (b) repeats the "never touches" folklore, which is true only of vertical asymptotes and false in general. (c) solves x² + 1 = 0 as if it were x² − 1 = 0 — the standard sign slip, and one that would put asymptotes on a function that has none. (d) applies the equal-degree rule to unequal degrees: deg(numerator) = 1 < deg(denominator) = 2, so the correct rule gives limit 0, not the coefficient ratio 2/1.

**5.** *Concept: the same formula can produce a hole or no break at all, depending entirely on the value the definition supplies at the point.* For every x ≠ 3, (x² − 9)/(x − 3) = (x − 3)(x + 3)/(x − 3) = **x + 3**, so away from 3 both graphs are the straight line y = x + 3, and both one-sided limits at 3 are 3 + 3 = **6**. **f:** lim_{x→3⁻} f = 6, lim_{x→3⁺} f = 6, so lim_{x→3} f = **6**; f(3) = **2**. Graph: the line y = x + 3 with an **open circle at (3, 6)** and a lone **filled dot at (3, 2)**, three units below the line. Conditions (i) and (ii) hold, (iii) fails, so f is **not continuous** at 3; the discontinuity is **removable**, and the repair is to redefine f(3) := 6, i.e. slide the filled dot up onto the line. **g:** the left rule is the same quotient, so lim_{x→3⁻} g = **6**; the right rule is 2x, so lim_{x→3⁺} g = 2(3) = **6**; equal, so lim_{x→3} g = **6**. The right rule also governs the point itself, so g(3) = **6**. Graph: the line y = x + 3 arriving from the left at a point that is **filled, at (3, 6)** — no open circle survives, because the second rule supplies exactly the missing value — and the line y = 2x leaving that same point (2x passes through (3, 6) too, with slope 2 instead of 1, so the curve continues with a **corner** but no break). All three conditions hold: **g is continuous at 3**. The corner is irrelevant to continuity; it would matter only for differentiability. The moral is that neither the appearance of 0/0 in the formula nor the use of two separate rules decides anything — only whether the supplied value equals the common branch height.

**6.** *Concept: at a vertical asymptote the sign test on each side decides whether the failure can be described by a single symbol, but no amount of agreement between the two sides turns an infinite limit into a number.* **g(x) = 1/(x − 2):** for x slightly less than 2, x − 2 is a small negative number, so lim_{x→2⁻} g = **−∞** and the left branch plunges down the line x = 2; for x slightly more than 2 it is small positive, so lim_{x→2⁺} g = **+∞** and the right branch climbs it. Far out in both directions the branches flatten toward y = 0. **h(x) = 1/(x − 2)²:** the denominator is a **square**, hence strictly positive on **both** sides, so lim_{x→2⁻} h = **+∞** and lim_{x→2⁺} h = **+∞**; both branches climb the asymptote, and the graph sits entirely above the x-axis, again flattening toward y = 0 far out. We write lim_{x→2} h(x) = +∞ because the two sides fail in the **same** way, so a single symbol describes the whole neighbourhood; for g the two sides run to opposite infinities, so there is no single description and the only honest answer is "does not exist". But this is a difference of **notation, not of status**: +∞ is not a real number, so h has no limit at 2 either — "= +∞" is a report on how the limit fails, not a value it attains. Neither discontinuity is removable, because removability requires the two branches to already agree on a **finite** common height, so that supplying one missing value closes the gap; here the branches are unbounded, and no real value assigned to g(2) or h(2) can be approached by a function that grows past every bound. Both are **infinite discontinuities**, and x = 2 is a vertical asymptote of each.
