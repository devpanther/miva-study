# Monday — MTH_102 nightly check

*Graphical limits theory: reading limits and f(a) off a plot, one-sided limits and the existence test, the three modes of failure, continuity and the classification of discontinuities, asymptotes as limit statements.*
*Sit cold, notes closed, 8 minutes. Score out of 6.*

**1.** A function f is plotted as follows: for x < 4 the curve rises steadily and ends at an **open circle at (4, 2)**; for x > 4 the curve falls steadily and begins at an **open circle at (4, 2)**; and a single **filled dot sits at (4, −1)**, off the curve. Which statement is correct?
a) lim_{x→4} f(x) = −1, since the filled dot is the only point actually on the graph at x = 4
b) lim_{x→4} f(x) = 2 and f has a removable discontinuity at 4, because the limit exists but disagrees with f(4) = −1
c) lim_{x→4} f(x) does not exist, because the value the branches approach differs from the value f actually takes at 4
d) lim_{x→4} f(x) = 2 and f is continuous at 4, since both one-sided limits exist and are equal

**2.** For a function f, lim_{x→1⁻} f(x) = +∞ and lim_{x→1⁺} f(x) = +∞. Which statement is correct?
a) The two one-sided limits exist and are equal, so the existence test is satisfied and lim_{x→1} f(x) exists with the value +∞
b) lim_{x→1} f(x) does not exist and x = 1 is a jump discontinuity, since the graph is broken at x = 1 and the two branches are separated
c) No real-number limit exists; we write lim_{x→1} f(x) = +∞ only as shorthand for unbounded growth on both sides, and x = 1 is a vertical asymptote — an infinite discontinuity
d) lim_{x→1} f(x) = +∞, so f is discontinuous at 1 unless f(1) is also defined to be +∞, in which case the three continuity conditions are met

**3.** Which statement about asymptotes as limit statements is correct?
a) x = a is a vertical asymptote exactly when f(a) is undefined; y = L is a horizontal asymptote exactly when the graph gets close to y = L without ever reaching it
b) x = a is a vertical asymptote when at least one one-sided limit at a is +∞ or −∞; y = L is a horizontal asymptote when lim_{x→+∞} f(x) = L or lim_{x→−∞} f(x) = L, and the curve may cross y = L any number of times
c) x = a is a vertical asymptote only when both one-sided limits at a are infinite **with the same sign**; y = L is a horizontal asymptote when the curve approaches y = L but never touches it
d) x = a is a vertical asymptote wherever lim_{x→a} f(x) fails to exist; y = L is a horizontal asymptote wherever the graph levels off and stays near height L over some interval

**4.** f is defined by f(x) = (x² − 4)/(x − 2) for x ≠ 2, together with f(2) = 4. What does the graph do at x = 2?
a) It has a hole: an open circle at (2, 4) and a removable discontinuity, because the defining formula is undefined at x = 2
b) Nothing at all: the graph is the straight line y = x + 2 carrying a **filled** dot at (2, 4), the limit is 4, f(2) = 4, and f is continuous at 2
c) It has a jump, because two separate rules are used to define f and the rules disagree in form at x = 2
d) It has an infinite discontinuity with a vertical asymptote x = 2, because the denominator vanishes there and the quotient blows up

**5. (explain why)** State the three conditions for f to be continuous at a point c. For each condition **separately**, describe in words what the graph looks like when that one condition is the only one to fail, and name the type of discontinuity produced. Then explain why "f(c) is undefined" is not, on its own, a classification.

**6. (explain why)** At x = 0, each of these fails to have a limit: p(x) = |x|/x, q(x) = 1/x, r(x) = sin(1/x). Describe what each graph does near 0, name the mode of failure and the type of discontinuity in each case, and explain precisely why only one of the three counts as a *jump*.

## Answers

**1. b** — *The limit is determined by the branches; f(a) is determined by the filled dot; continuity requires the two to be numbers and to be the same number.* Both branches end at height 2, so lim_{x→4⁻} f = lim_{x→4⁺} f = 2 and the limit exists and equals 2. The filled dot gives f(4) = −1. Conditions (i) and (ii) of continuity hold, condition (iii) fails, so f is discontinuous at 4 — and since the limit exists, the discontinuity is **removable**: redefine f(4) := 2 and the hole is filled. (a) reads the value off the dot and calls it the limit, the commonest graph error; the dot is the one point the limit never inspects. (c) treats a mismatch between limit and value as destroying the limit — it destroys only continuity, which is exactly what "removable" means. (d) checks the first two conditions and stops, forgetting that continuity also demands limit = f(4); it would be right if the dot at (4, −1) were absent and (4, 2) were filled instead.

**2. c** — *The existence test requires two **finite** equal one-sided values; ±∞ is a description of how a limit fails, never a value it takes.* Both branches run up the line x = 1 without bound, so f is unbounded near 1: no real number L can be approached. The conventional notation lim_{x→1} f(x) = +∞ records that the failure is of the same kind on both sides; it is a statement about behaviour, not a limit value. Graphically this is a vertical asymptote at x = 1 and an **infinite discontinuity**. (a) is the trap: it applies the existence test mechanically to two symbols that are not numbers. (b) misclassifies — a jump requires both one-sided limits to be finite and merely different; here neither is finite. (d) compounds (a) by trying to satisfy the continuity conditions with f(1) = +∞, but +∞ is not in the range of a real-valued function, so f(1) cannot be defined to be it and no repair exists.

**3. b** — *An asymptote is not a geometric "line never touched"; it is a shorthand for a limit statement, vertical ones about x → a and horizontal ones about x → ±∞.* One infinite one-sided limit is enough for a vertical asymptote (f(x) = 1/(x − 3) has −∞ on the left and +∞ on the right, and x = 3 is an asymptote all the same). A horizontal asymptote constrains only the far-out behaviour, so crossings are permitted: 2x/(x² + 1) crosses y = 0 at the origin, and sin(x)/x crosses it infinitely often. (a) confuses being undefined with blowing up — a hole is undefined and has no asymptote — and repeats the "never reaches it" folklore. (c) over-tightens the vertical condition, which would wrongly deny that x = 3 is an asymptote of 1/(x − 3), and repeats the same folklore. (d) is far too loose in both halves: jumps and oscillations make limits fail with no asymptote in sight, and levelling off over an interval is a local flatness, not a limit as x → ∞.

**4. b** — *A formula that reads 0/0 at a point does not by itself put a discontinuity there; what matters is whether the supplied value equals the limit.* For every x ≠ 2, (x² − 4)/(x − 2) = (x − 2)(x + 2)/(x − 2) = x + 2, so the graph is the line y = x + 2 with the single point x = 2 governed by the second rule. Both branches head for height 4; the rule sets f(2) = 4; the dot therefore lands exactly on the line and the pen never lifts. All three continuity conditions hold. (a) is the near-miss and the discriminating distractor: it correctly spots that the *formula* is undefined at 2, but forgets that the piecewise definition supplies the value, so the circle is filled, not open. (c) treats "defined by two rules" as automatically producing a jump — Week 3 already disposed of that; a jump needs *unequal one-sided limits*, and here they are both 4. (d) confuses 0/0 with k/0: a vanishing denominator gives an asymptote only when the numerator does **not** also vanish.

**5.** *Concept: continuity at c is the conjunction of three independent conditions, and each failure mode has its own picture and its own name.* The conditions are **(i)** f(c) is defined; **(ii)** lim_{x→c} f(x) exists — both one-sided limits exist, are finite and agree; **(iii)** lim_{x→c} f(x) = f(c). **If only (i) fails:** the two branches meet at a common height L but nothing is filled in there — the graph shows an **open circle at (c, L)** and no filled dot anywhere on the line x = c. This is a **removable discontinuity**, repaired by defining f(c) := L. **If only (iii) fails:** the branches still meet at L, so there is an open circle at (c, L), but a **filled dot sits elsewhere on the line x = c**, at (c, f(c)) with f(c) ≠ L. Also **removable** — move the dot onto the curve. **If (ii) fails:** the branches do not agree, and (i) may well still hold. Two different finite heights ⟹ a visible vertical gap, a **jump**; a branch running off along the line x = c ⟹ a vertical asymptote, an **infinite** discontinuity; a branch that never settles ⟹ **essential/oscillatory**. Note that (iii) presupposes both (i) and (ii), so "only (ii) fails" is the case where f(c) exists but is stranded. Finally, "f(c) is undefined" is not a classification because it says nothing about the branches, which are what the classification is built from: an undefined point can carry a hole (limit exists), a jump (the one-sided limits exist and differ) or an asymptote (they are infinite) — three different diagnoses and three different verdicts on repairability, all sharing the same missing dot.

**6.** *Concept: the three modes of limit failure are distinguished by what happens to the **one-sided** limits, not by how broken the picture looks.* **p(x) = |x|/x** equals −1 for every x < 0 and +1 for every x > 0: the graph is two horizontal rays, one at height −1 to the left of the y-axis, one at height +1 to the right, each ending in an open circle at (0, −1) and (0, +1) respectively, with no dot on the y-axis. lim_{x→0⁻} p = −1 and lim_{x→0⁺} p = +1: both **exist and are finite**, and they differ — a **jump discontinuity**, of size 2. **q(x) = 1/x**: to the left of 0 the branch plunges down the y-axis (lim_{x→0⁻} q = −∞), to the right it climbs it (lim_{x→0⁺} q = +∞), and both flatten toward y = 0 far out. The failure is **infinite**, x = 0 is a **vertical asymptote**, and we cannot even write ±∞ for the two-sided limit because the signs disagree. **r(x) = sin(1/x)**: every interval (0, δ) contains infinitely many complete waves running between the heights −1 and +1, compressing endlessly as x → 0; the same on the left. No branch heads for any height, so the **one-sided limits themselves do not exist** — an **essential (oscillatory)** discontinuity, with the function nevertheless bounded, so no asymptote. Only p is a jump, because a jump is *defined* by both one-sided limits existing as finite numbers and merely disagreeing. q fails that because its one-sided limits are not finite; r fails it because its one-sided limits do not exist at all. And this is why only these last two are unfixable by any redefinition at a single point, while even p's gap of size 2 cannot be bridged by one value either — repairability belongs only to the removable case, where the branches already agree.
