**31.** f(x) = (2x + 5)/(x − 4).

**(a) Domain.** The only restriction is the denominator: x − 4 ≠ 0 ⟹ x ≠ 4.
**dom(f) = ℝ \ {4}.**

**(b) Range.** Put y = (2x + 5)/(x − 4) and solve for x:
y(x − 4) = 2x + 5
yx − 4y = 2x + 5
yx − 2x = 5 + 4y
x(y − 2) = 4y + 5
x = (4y + 5)/(y − 2).
This produces an x for every value of y except y = 2, where the denominator vanishes.
**ran(f) = ℝ \ {2}.**

**(c) Inverse.** The rearrangement in (b) already gives x in terms of y; swapping the names,
**f⁻¹(x) = (4x + 5)/(x − 2).**
The domain/range swap is:
**dom(f⁻¹) = ran(f) = ℝ \ {2}** and **ran(f⁻¹) = dom(f) = ℝ \ {4}.**

*Tests: the three domain rules, finding a range by algebraic inversion, and the inverse with the domain/range swap stated rather than assumed.* **[Week 1]**

**32.** f(x) = (x² − 1)/(x² − 3x + 2).

**(a) The hole.** Factor both parts:
x² − 1 = (x − 1)(x + 1);  x² − 3x + 2 = (x − 1)(x − 2).
So f(x) = [(x − 1)(x + 1)] / [(x − 1)(x − 2)]. The factor (x − 1) cancels, so x = 1 is a **hole**, not an asymptote. The reduced function is g(x) = (x + 1)/(x − 2), and the hole's height is g(1) = (1 + 1)/(1 − 2) = 2/(−1) = −2.
**Hole at (1, −2)**, drawn as an open circle.

**(b) Asymptotes.**
**Vertical asymptote x = 2** — it is the denominator zero that survives the cancelling.
**Horizontal asymptote y = 1** — numerator and denominator both have degree 2, so the asymptote is the ratio of leading coefficients, 1/1 = 1.

**(c) Intercepts and behaviour at the asymptote.**
x-intercept: set the reduced numerator to zero, x + 1 = 0 ⟹ x = −1, which is in the domain, giving **(−1, 0)**.
y-intercept: f(0) = (0 − 1)/(0 − 0 + 2) = −1/2, giving **(0, −1/2)**.
Near x = 2, use g(x) = (x + 1)/(x − 2). As x → 2⁻ the numerator → 3 > 0 while the denominator → 0⁻, so **f(x) → −∞**. As x → 2⁺ the denominator → 0⁺, so **f(x) → +∞**.

*Tests: cancelling before declaring asymptotes, the equal-degree rule for the horizontal asymptote, and one-sided sign work at a vertical asymptote.* **[Week 2]**

**33.**

**(a) lim_{x→3} (x² − x − 6)/(x² − 9).**
Substitute: (9 − 3 − 6)/(9 − 9) = 0/0 — indeterminate, so substitution decides nothing. **Method: factorization.**
x² − x − 6 = (x − 3)(x + 2);  x² − 9 = (x − 3)(x + 3).
lim_{x→3} [(x − 3)(x + 2)]/[(x − 3)(x + 3)] = lim_{x→3} (x + 2)/(x + 3)  (cancelling is legal because x ≠ 3 throughout)
= (3 + 2)/(3 + 3) = **5/6**.

**(b) lim_{x→0} (√(9 + x) − 3)/x.**
Substitute: (√9 − 3)/0 = 0/0. **Method: rationalization** — multiply above and below by the conjugate √(9 + x) + 3:
[(√(9+x) − 3)(√(9+x) + 3)] / [x(√(9+x) + 3)] = (9 + x − 9) / [x(√(9+x) + 3)] = x / [x(√(9+x) + 3)]
= 1/(√(9 + x) + 3) for x ≠ 0.
Now substitute: 1/(3 + 3) = **1/6**.

**(c) lim_{x→0} (sin 3x)/(5x).**
Substitute: sin 0 / 0 = 0/0, and both functions are differentiable near 0, so **L'Hôpital's Rule** applies. Differentiate numerator and denominator *separately*:
d/dx (sin 3x) = 3 cos 3x;  d/dx (5x) = 5.
lim_{x→0} (3 cos 3x)/5 = 3(1)/5 = **3/5**.

*Tests: choosing the right method for each 0/0 — factor, conjugate, L'Hôpital — and checking the form before choosing.* **[Week 3]**

**34.** f(x) = x + 3 for x < 1; f(1) = 2; f(x) = x² + 3 for x > 1.

**(a) One-sided limits.**
From the left, x < 1, so use x + 3: lim_{x→1⁻} f(x) = 1 + 3 = **4**.
From the right, x > 1, so use x² + 3: lim_{x→1⁺} f(x) = 1² + 3 = **4**.
The two agree, so **lim_{x→1} f(x) = 4** — the two-sided limit exists.

**(b) Continuity check, condition by condition.**
(i) f(1) is defined: yes, f(1) = 2. ✔
(ii) lim_{x→1} f(x) exists: yes, it is 4. ✔
(iii) lim_{x→1} f(x) = f(1): 4 ≠ 2. ✘
So **f is not continuous at x = 1**; the failure is **condition (iii)** only — both (i) and (ii) hold. Note that f being defined at 1 is not enough on its own.

**(c) Classification and repair.**
The one-sided limits are equal and finite (L⁻ = L⁺ = 4) while f(1) is defined at the wrong height, so this is a **removable discontinuity** — a hole at (1, 4) with the stray plotted point (1, 2) sitting below it.
**Repair:** redefine f(1) = 4. All three conditions then hold and f is continuous at 1.

*Tests: evaluating one-sided limits from a piecewise rule, and naming which of the three continuity conditions actually fails rather than just saying "discontinuous".* **[Week 4]**

**35.** h(x) = (x + 1)/(x − 3).

**(a) Solve h(x) ≤ 2.**
Do **not** multiply both sides by (x − 3): its sign is unknown, so the inequality direction cannot be decided. Instead collect on one side over a common denominator:
(x + 1)/(x − 3) − 2 ≤ 0
[(x + 1) − 2(x − 3)]/(x − 3) ≤ 0
(x + 1 − 2x + 6)/(x − 3) ≤ 0
(7 − x)/(x − 3) ≤ 0
Multiply by −1 and **flip** the inequality: (x − 7)/(x − 3) ≥ 0.
Critical values: x = 3 (denominator zero, undefined) and x = 7 (numerator zero).
Sign chart, testing one point per interval:
x = 0: (−7)/(−3) = +  ✔ (satisfies ≥ 0)
x = 5: (−2)/(2) = −  ✘
x = 8: (1)/(5) = +  ✔
Endpoints: x = 7 gives 0, and "≥ 0" allows equality, so **include** 7; x = 3 is undefined, so **exclude** it.
**Solution: (−∞, 3) ∪ [7, ∞).**

**(b) One-sided limits at 3.**
As x → 3⁻: the numerator → 3 + 1 = 4 > 0 and the denominator → 0 through negative values, so **lim_{x→3⁻} h(x) = −∞**.
As x → 3⁺: the numerator → 4 > 0 and the denominator → 0 through positive values, so **lim_{x→3⁺} h(x) = +∞**.
Neither is a finite real number, and in any case they disagree, so **lim_{x→3} h(x) does not exist**.

**(c) Classification.**
At least one one-sided limit is ±∞ and the graph hugs the line x = 3, so x = 3 is an **infinite discontinuity** (vertical asymptote). It is **not removable**: no single value assigned to h(3) can create a limit that does not exist to begin with.

*Tests: the rational-inequality method with the sign flip, one-sided sign analysis at a denominator zero, and the jump-versus-infinite distinction.* **[Weeks 2, 3 & 4]**

**36.** f(x) = (√(x + 7) − 3)/(x − 2).

**(a) Domain.**
Two restrictions. Even-root radicand ≥ 0: x + 7 ≥ 0 ⟹ x ≥ −7. Denominator ≠ 0: x − 2 ≠ 0 ⟹ x ≠ 2.
**dom(f) = [−7, 2) ∪ (2, ∞).**

**(b) The limit as x → 2.**
Direct substitution: (√(2 + 7) − 3)/(2 − 2) = (√9 − 3)/0 = (3 − 3)/0 = **0/0**, which is indeterminate — it tells us nothing yet, so more algebra is needed.

*Rationalization.* Multiply numerator and denominator by the conjugate √(x + 7) + 3:
[(√(x+7) − 3)(√(x+7) + 3)] / [(x − 2)(√(x+7) + 3)]
= [(x + 7) − 9] / [(x − 2)(√(x+7) + 3)]
= (x − 2) / [(x − 2)(√(x+7) + 3)]
= 1/(√(x + 7) + 3)  for x ≠ 2 (the cancelling is valid because x never equals 2 in the limit process).
Now substitute: lim_{x→2} f(x) = 1/(√9 + 3) = 1/(3 + 3) = **1/6**.

*Confirmation by L'Hôpital's Rule.* The form is 0/0 and both functions are differentiable near 2, so the rule is licensed. Differentiate numerator and denominator separately:
d/dx [√(x + 7) − 3] = 1/(2√(x + 7));  d/dx (x − 2) = 1.
lim_{x→2} [1/(2√(x + 7))] / 1 = 1/(2√9) = 1/(2 · 3) = **1/6**.
The two methods agree.

**(c) The discontinuity at x = 2.**
f(2) is undefined (condition (i) fails), but the two-sided limit exists and is finite, equal to 1/6, so the one-sided limits are equal: L⁻ = L⁺ = 1/6. That is exactly a **removable discontinuity** — a hole at (2, 1/6).
Setting **f(2) = 1/6** makes all three continuity conditions hold, so the repaired function is continuous at 2.

*Tests: the domain rules on a radical-over-linear function, two independent 0/0 methods giving the same value, and the removable classification with its repair.* **[Weeks 1, 3 & 4]**
