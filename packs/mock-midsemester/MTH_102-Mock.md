**1. a** — *Two domain rules combined*: the even root needs x + 2 ≥ 0 ⟹ x ≥ −2; the denominator (x − 4)(x + 3) ≠ 0 ⟹ x ≠ 4, x ≠ −3, and −3 is already outside x ≥ −2. (b) applies only the root rule; (c) applies only the denominator rule and keeps −3, which the root has already killed; (d) reads the even-root rule as radicand > 0. **[Week 1]**

**2. a** — *Range by completing the square*: 7 − 4x − x² = −(x² + 4x) + 7 = −(x + 2)² + 11, so f(x) ≤ 11 with equality at x = −2. (b) treats a downward parabola as having a minimum; (c) reads the constant term as the extreme value; (d) reports the vertex's x-coordinate as if it bounded the outputs. **[Week 1]**

**3. a** — *Range by algebraic inversion*: y(x + 3) = 4x − 1 ⟹ x(y − 4) = −(3y + 1) ⟹ x = (3y + 1)/(4 − y), defined for every y except 4. (b) quotes the **domain** exclusion; (c) quotes the x-intercept 1/4; (d) forgets that a rational function of this shape misses exactly one height. **[Week 1]**

**4. a** — *Domain of a composite is not the domain of g*: (f∘g)(x) = 2/((x² + 1) − 5) = 2/(x² − 4), so x² ≠ 4 ⟹ x ≠ ±2. (b) applies dom(f) to x itself instead of to g(x); (c) takes dom(f∘g) = dom(g) = ℝ; (d) solves x² = 4 keeping only the positive root. **[Week 1]**

**5. a** — *Composite order, g first*: g(1) = 1/3, then f(1/3) = 1/9 − 1 = **−8/9**. (b) is the same arithmetic with the subtraction reversed; (c) is (g∘f)(1) = g(0) = 1/2, i.e. the composition done in the wrong order; (d) is f(1)·g(1), reading f∘g as the product fg. **[Week 1]**

**6. a** — *Finding an inverse*: y(x − 4) = 2x + 7 ⟹ x(y − 2) = 4y + 7 ⟹ x = (4y + 7)/(y − 2); rename. (b) is 1/f(x), the reciprocal mistaken for the inverse; (c) mis-signs both transpositions; (d) divides by (2 − y) instead of (y − 2), flipping one sign only. **[Week 1]**

**31.**
(a) g(x) = x² − 2x − 3 = (x − 1)² − 4 ≥ −4, equality at x = 1, so **range = [−4, ∞)**. The codomain is the declared ℝ, and no output below −4 is ever achieved, so **range ⊊ codomain**.
(b) The curve falls and then rises, so a horizontal line drawn at any height above −4 cuts it **twice** (once on each arm) — the horizontal line test fails, g is **not injective**, hence not bijective, and **g⁻¹ does not exist** as a function on ℝ. (The vertical line test does pass, so g is a function.)
(c) On [1, ∞) only the rising arm survives, so g is injective there. y = (x − 1)² − 4 ⟹ (x − 1)² = y + 4 ⟹ x − 1 = +√(y + 4) (the positive root, since x ≥ 1) ⟹ x = 1 + √(y + 4). So **g⁻¹(x) = 1 + √(x + 4)**, with **dom(g⁻¹) = ran(g) = [−4, ∞)** and **ran(g⁻¹) = dom(g) = [1, ∞)**.
— *Range by completing the square; the horizontal line test and invertibility; the domain/range swap.* **[Week 1]**

**32.** Factor both: (x − 3)(x + 2)/((x − 3)(x + 1)). The factor (x − 3) cancels, so:
**Hole** at x = 3, height from the reduced form (3 + 2)/(3 + 1) = 5/4 — the open point **(3, 5/4)**.
**Vertical asymptote** x = **−1** (the surviving zero). **Horizontal asymptote**: degrees equal ⟹ y = 1/1 = **y = 1**.
**x-intercept**: numerator zero that survives, x + 2 = 0 ⟹ **(−2, 0)**. **y-intercept**: f(0) = (−6)/(−3) = **2**, i.e. (0, 2).
**Near x = −1** use the reduced (x + 2)/(x + 1): as x → −1⁻ the top → 1 > 0 and the bottom → 0⁻, so f → **−∞**; as x → −1⁺ the bottom → 0⁺, so f → **+∞**.
**Meeting the HA**: set (x + 2)/(x + 1) = 1 ⟹ x + 2 = x + 1 ⟹ 2 = 1, impossible — so the graph **never crosses y = 1**. (Equivalently f = 1 + 1/(x + 1), and 1/(x + 1) is never 0.)
— *Full rational analysis: hole vs asymptote, degree comparison, sign check at the asymptote.* **[Week 2]**

**33.**
(a) Substitution gives 0/0. **Rationalisation** — multiply top and bottom by the conjugate (√(x + 5) + 3): the bottom becomes (x + 5) − 9 = x − 4, so the quotient is (x − 4)(√(x + 5) + 3)/(x − 4) = √(x + 5) + 3 for x ≠ 4. Substitute: **6**. (Note the conjugate here belongs to the *denominator*.)
(b) **Divide top and bottom by the highest power, x²**: (2 − 3/x)/(5/x² − 1) → (2 − 0)/(0 − 1) = **−2**. Equal degrees, so the ratio of leading coefficients 2/(−1) — and the sign of the leading coefficient of the bottom must be carried; x → −∞ rather than +∞ changes nothing, since every surviving term is even-powered.
(c) Stacked fractions ⟹ **common denominator first**: 1/(x + 2) − 1/2 = (2 − (x + 2))/(2(x + 2)) = −x/(2(x + 2)). Dividing by x gives −1/(2(x + 2)) for x ≠ 0. Substitute: −1/(2·2) = **−1/4**.
— *Matching the technique to the shape of the indeterminate form.* **[Week 3]**

**34.**
(a) f is continuous at a iff **(i)** f(a) is defined, **(ii)** lim_{x→a} f(x) exists, **(iii)** the two are equal. Here x³ − 8 = (x − 2)(x² + 2x + 4), so for x ≠ 2 the function is x² + 2x + 4, whose limit as x → 2 is 4 + 4 + 4 = **12**. f(2) = 12 is defined, the limit exists, and 12 = 12 — all three hold, so **f is continuous at 2**.
(b) Substitution gives 5/0, which is **not** 0/0 or ∞/∞, so the hypothesis of L'Hôpital's rule fails and the rule may not be used. Using it anyway gives 2x/1 → **4**, which is flatly wrong. The truth is a sign check: as x → 2⁻ the bottom → 0⁻ with top → 5, so f → **−∞**; as x → 2⁺, f → **+∞**; the limit **does not exist**.
(c) **Squeeze theorem**: if g(x) ≤ f(x) ≤ h(x) for all x near a (x ≠ a) and lim_{x→a} g = lim_{x→a} h = L, then lim_{x→a} f = L. Since −1 ≤ cos(3/x) ≤ 1 and x⁴ ≥ 0, we get **−x⁴ ≤ x⁴cos(3/x) ≤ x⁴**; both bounds → 0 as x → 0, so the limit is **0**. (The product law is unusable: lim cos(3/x) does not exist.)
— *The three conditions; the hypothesis of L'Hôpital's rule; two-sided bounds with a common limit.* **[Week 3]**

**35.** At x = −3: lim_{x→−3⁻} f = **−∞**, lim_{x→−3⁺} f = **+∞**, so lim_{x→−3} f **DNE**, and with no dot on that vertical line **f(−3) is undefined** — an **infinite discontinuity** (vertical asymptote x = −3), which **cannot be repaired**.
At x = 1: lim_{x→1⁻} f = **4**, lim_{x→1⁺} f = **4** (an open circle still tells you the height the curve heads for), so lim_{x→1} f = **4**; the shaded dot gives **f(1) = −1**. Condition (iii) fails — a **removable discontinuity**, **repaired** by redefining **f(1) = 4**.
At the ends: lim_{x→−∞} f = **2** and lim_{x→+∞} f = **5** — the two horizontal asymptotes, which may differ.
— *Reading limits, values and discontinuity type off a graph; open circle gives the limit, shaded dot gives the value.* **[Week 4]**

**36.**
(a) (i) **f(4) = 3**, defined. (ii) Left: (x² − 16)/(x − 4) = (x − 4)(x + 4)/(x − 4) = x + 4 for x ≠ 4, so lim_{x→4⁻} f = **8**; right: lim_{x→4⁺} 2x = **8**. They agree, so lim_{x→4} f = **8**, exists. (iii) 8 ≠ 3, so **condition (iii) fails** — a **removable discontinuity**. Redefining **f(4) = 8** repairs it.
(b) With 3x on the right: lim_{x→4⁻} f = **8** still, but lim_{x→4⁺} f = 3(4) = **12**. Both one-sided limits exist and are finite but **unequal**, so lim_{x→4} f **DNE** — **condition (ii)** now fails, and this is a **jump discontinuity**. No choice of f(4) can help: f(4) is a single number, and moving it changes only condition (i)/(iii), never the two one-sided limits, which are what disagree.
— *Three-condition test on a piecewise function; only a removable discontinuity can be repaired by moving one point.* **[Week 4]**
