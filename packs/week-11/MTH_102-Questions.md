## Section A — Multiple choice (12)

**1.** The region under y = 1/x from x = 1 to x = 3, revolved about the x-axis, has volume:
a) 2π/3   b) π ln 3   c) −2π/3   d) 26π/3

**2.** The region under y = f(x) ≥ 0 on [a, b], with 0 ≤ a < b, is revolved about the **y-axis**. Its volume is:
a) π∫ₐᵇ[f(x)]²dx   b) 2π∫ₐᵇx f(x)dx   c) 2π∫ₐᵇf(x)dx   d) π∫ₐᵇx²f(x)dx

**3.** The region bounded by y = x², y = 0, x = 0 and x = 3 is revolved about the line **x = 4**. The correct set-up is:
a) 2π∫₀³x·x²dx
b) 2π∫₀³(x − 4)x²dx
c) 2π∫₀³(4 − x)x²dx
d) π∫₀³(4 − x)²dx

**4.** The region between y = 3 and y = x + 1 on [0, 1], revolved about the x-axis, has volume:
a) −20π/3   b) 7π/3   c) 15π/2   d) 20π/3

**5.** The region under y = 2x from x = 0 to x = 3, revolved about the x-axis, has volume:
a) 9π   b) 18π   c) 36π   d) 108π

**6.** Of the following, the one that **cannot** be done by discs or washers and genuinely needs shells is:
a) the region under y = x² on [0, 2], about the x-axis
b) the region bounded by y = √x, y = 0, x = 4, about the y-axis
c) the region bounded by y = x⁵ + x, y = 0 and x = 1, about the y-axis
d) the region bounded by x = y², y = 0 and y = 2, about the y-axis

**7.** The lens-shaped region bounded above by y = 1 − x² and below by y = x² − 1 is revolved about the **x-axis**. The volume is:
a) 0   b) 8π/15   c) 16π/15   d) 32π/15

**8.** The region bounded by x = y², the y-axis and the line y = 3, revolved about the **y-axis**, has volume:
a) 9π   b) 81π/2   c) 243π/5   d) 486π/5

**9.** A **washer** integral for a rotation about the line x = 5 must be written in:
a) dx   b) dy   c) either, since the two are related by the chain rule   d) dx if the curve is given as y = f(x), dy if it is given as x = g(y)

**10.** The region bounded by y = x², y = 0 and x = 2 is revolved about the **x-axis** and set up by the **shell** method. The correct integral is:
a) 2π∫₀⁴y(2 − √y)dy
b) 2π∫₀²x·x²dx

**11.** The region bounded by y = x, y = 0 and x = 1, revolved about the line **y = 1**, has volume:
a) π/3   b) 2π/3   c) π   d) 4π/3

**12.** For one region and one axis, when both set-ups are possible, the disc/washer method and the shell method:
a) give different answers, and the washer answer is the exact one

c) give the same answer only when the region touches the axis of revolution
d) cannot both be applied to the same region, since the slices point in different directions

## Section B — Short answer (3)

**13.** Derive the shell element dV = 2πx·h(x)dx from the volume of a thin cylindrical tube, saying exactly which term is discarded and why that is legitimate. Then use it to find the volume generated by revolving the region bounded by y = 4 − x² and y = 0 about the y-axis, and verify your answer by a washer integral.

**14.** The region enclosed by y = x and y = x² is revolved about the line **y = −1**. Set up and evaluate the volume, justifying which curve gives the outer radius. Compare your answer with the volume 2π/15 obtained for the same region about the x-axis, and explain in one sentence why the shift makes the solid larger.

**15.** The region bounded by y = √x, y = 0 and x = 9 is revolved about three different axes: (i) the x-axis, (ii) the y-axis, (iii) the line x = 9. For each, name the method you would use and the variable of integration, justify the choice, set up the integral and evaluate it.

## Answers

1. **a** — *Disc method: the radius is squared before integrating, and 1/x² integrates by the power rule, not to a logarithm.* R = 1/x, so V = π∫₁³x⁻²dx = π[−1/x]₁³ = π(−1/3 + 1) = 2π/3. (b) is π∫₁³(1/x)dx = π ln 3 — the radius was never squared, so an area has been dressed up as a volume; the appearance of a logarithm in a disc problem with a rational radius is itself the warning. (c) evaluates [−1/x] as (lower − upper), giving −2π/3, and a negative volume is always a signal, never an answer. (d) is π∫₁³x²dx = 26π/3, obtained by "squaring" 1/x into x² — the reciprocal was inverted rather than squared.
2. **b** — *Shells about a vertical axis: 2π × radius × height × thickness, with the radius measured from the axis.* The strip at x sweeps a tube of radius x and height f(x); unrolled it is a slab 2πx by f(x) by dx. (a) is the disc formula, correct only for rotation about the **x**-axis — same region, different solid; (c) drops the radius x, which gives every shell the same radius and is dimensionally an area times a length only by accident; (d) mixes the two families, using π with a radius-squared factor multiplied by a height, which describes nothing: π∫R²dx already contains the whole slab, and multiplying by f(x) as well double-counts.
3. **c** — *A shell's radius is the distance from the axis, and the region lies to the left of x = 4.* Every point of the region has 0 ≤ x ≤ 3 < 4, so the distance to the axis is 4 − x, the height is x², the thickness is dx, and V = 2π∫₀³(4 − x)x²dx. (b) reverses the radius to x − 4, negative throughout, and returns the correct volume with a minus sign; (a) uses radius x, which is the distance from the **y-axis**, so it answers a different question entirely — and it is the hardest error to catch because the integral is perfectly well behaved; (d) applies the disc formula π∫R²dx to a shell radius, but discs about a vertical axis must stack in y, so a dx there is self-contradictory.
4. **d** — *Washer: outer radius is the distance from the axis to the further boundary, and the squares are taken separately.* On [0, 1] the line y = 3 is further from y = 0 than y = x + 1 (which runs from 1 to 2), so R = 3, r = x + 1. V = π∫₀¹[9 − (x + 1)²]dx = π[9x − (x + 1)³/3]₀¹ = π(19/3 + 1/3) = 20π/3. (b) is π∫₀¹(3 − x − 1)²dx = 7π/3, the (R − r)² error — the area of a circle whose radius is the *gap*, not the annulus; (c) is π∫₀¹[9 − (x + 1)]dx = 15π/2, squaring the outer radius but not the inner; (a) is the correct integrand with the radii interchanged.
5. **c** — *A disc integral over a straight line through the origin reproduces the cone formula πr²h/3.* R = 2x, so V = π∫₀³4x²dx = π[4x³/3]₀³ = 36π; and indeed the solid is a cone of base radius r = 6 and height h = 3, with πr²h/3 = π(36)(3)/3 = 36π. (a) is π∫₀³2x dx = 9π, the radius unsquared; (d) is πr²h = 108π, the enclosing **cylinder** — three times too big, and the factor 3 is exactly what the integration supplies; (b) is 18π, half the answer, from integrating over [0, 3] but taking r = 6 as though the radius were constant at half its final value.
6. **c** — *Discs and washers about a vertical axis need the boundary as x = g(y); shells do not.* y = x⁵ + x cannot be solved for x in closed form, so no washer integrand can be written, while shells need only radius x and height x⁵ + x: V = 2π∫₀¹x(x⁵ + x)dx. (a) is a rotation about a **horizontal** axis, where discs are stacked in x and the curve is already in the right form; (b) inverts painlessly to x = y² (with the outer radius the constant 4), so washers work; (d) is already given as x = g(y) about the y-axis, which is the disc method's ideal case. Note "needs shells" never means "the integral is hard" — it means the *inversion* is impossible.
7. **c** — *A region symmetric about the axis of revolution generates the same solid as either half; you integrate one half only, and you do not double it.* Both halves sweep the same solid of revolution, so V = π∫₋₁¹(1 − x²)²dx = π∫₋₁¹(1 − 2x² + x⁴)dx = 2π(1 − 2/3 + 1/5) = 16π/15. (d) doubles this on the grounds that there are two halves, counting the solid twice; (b) is the integral over [0, 1] only, which halves the *interval* rather than discarding the redundant half of the *region* — the two are different economies and only the second is legitimate; (a) is the seductive one: treating the lens as a washer with R = 1 − x² and r = x² − 1 gives R² − r² = 0 identically, and a volume of zero, because the "inner radius" is the reflection of the outer and not a hole at all. A region straddling the axis has no inner boundary.
8. **c** — *Discs about the y-axis: the radius is x = g(y), and the limits are y-values.* R(y) = y², so R² = y⁴ and V = π∫₀³y⁴dy = π[y⁵/5]₀³ = 243π/5. (a) is π∫₀³y²dy = 9π, the radius never squared (x = y² was mistaken for the radius squared); (b) is 2π∫₀³y·y²dy = 81π/2, the **shell** factor applied to a dy-integral about a vertical axis — shells about the y-axis run in dx, so this pairs the wrong formula with the wrong variable; (d) doubles the correct answer, the reflex of assuming symmetry in a region that has none below y = 0.
9. **b** — *Washer slices are perpendicular to the axis, so they stack along it; a vertical axis forces dy.* The annulus at height y has radii measured horizontally from x = 5, i.e. |g(y) − 5|, and these annuli are stacked in the y-direction. (a) is the swap that produces the impossible "π∫R(x)²dx about a vertical axis"; (c) is false — changing variable is not free, and no chain rule converts an annulus stacked in y into one stacked in x; (d) is the belief that the notation of the question fixes the variable, which is exactly what the inversion step exists to defeat: if the curve is given as y = f(x) and you want washers about x = 5, you must invert it or switch to shells.
10. **a** — *Shells about a horizontal axis are horizontal, so the radius is y, the thickness is dy, and the height is x_right − x_left.* At height y (0 ≤ y ≤ 4) the strip runs from the curve x = √y across to x = 2, so h(y) = 2 − √y and V = 2π∫₀⁴y(2 − √y)dy = 32π/5 (which agrees with the disc answer π∫₀²x⁴dx = 32π/5). (b) is the shell integral for the **y-axis**; (c) takes the height as √y, i.e. the left boundary alone rather than right minus left, and so builds the complementary solid; (d) has the correct integrand but x-limits in a dy-integral — a change of variable must carry the limits with it, exactly as in Week 10's horizontal strips.
11. **b** — *Rotation about y = 1 makes the x-axis the far boundary and the line y = x the near one, so it is a washer with R = 1 and r = 1 − x.* V = π∫₀¹[1² − (1 − x)²]dx = π∫₀¹(2x − x²)dx = π(1 − 1/3) = 2π/3. (a) is π∫₀¹(1 − x)²dx = π/3, the volume of the **hole** — the cone that has been removed, mistaken for the solid; (c) is π∫₀¹1²dx = π, the full cylinder with the hole never subtracted, and the correct answer must lie between π/3 and π; (d) is π∫₀¹[1 + (1 − x)²]dx = 4π/3, adding the inner disc instead of subtracting it, which cannot be right since it exceeds the enclosing cylinder.
12. **b** — *The two methods decompose the same solid in perpendicular directions, and both are exact, so they must agree.* Discs and washers cut the solid into plane cross-sections stacked along the axis; shells fill it with nested tubes stacked across the axis. Neither is an approximation once the limit is taken, so agreement is guaranteed and disagreement locates an error — which is why running the second method is the best available check. (a) invents a hierarchy: the shell's dx² term vanishes in the limit exactly as the disc's does, so neither is "more exact"; (c) confuses agreement with the disc condition — whether the region touches the axis decides disc versus washer, not whether the two families agree; (d) mistakes a difference in slicing direction for an incompatibility, when it is precisely that difference that makes one method easy where the other is impossible.
13. **V = 8π.** *Derivation.* A cylindrical tube of inner radius x, height h and thickness Δx has volume π(x + Δx)²h − πx²h = πh(2xΔx + Δx²) = 2πx·h·Δx + πh·Δx². The discarded term is **πh·Δx²**: it is second order in the thickness, so when the tube volumes are summed and Δx → 0 its total contribution tends to zero (n tubes each of order Δx² total order Δx → 0), while the first-order terms sum to the integral. Hence dV = 2πx·h(x)dx exactly in the limit. *Application.* y = 4 − x² meets y = 0 at x = ±2, and revolving about the y-axis it suffices to take the right half, 0 ≤ x ≤ 2 (the left half sweeps the same solid). Radius x, height 4 − x²: V = 2π∫₀²x(4 − x²)dx = 2π∫₀²(4x − x³)dx = 2π[2x² − x⁴/4]₀² = 2π(8 − 4) = **8π.** *Washer check:* invert to x = √(4 − y); the solid at height y (0 ≤ y ≤ 4) is a full disc of radius √(4 − y), so V = π∫₀⁴(4 − y)dy = π[4y − y²/2]₀⁴ = π(16 − 8) = **8π** ✓. — *Concept: the shell element is exact to first order, and a disc integral in the other variable confirms it.*
14. **V = 7π/15.** The curves meet where x = x², i.e. x = 0 and x = 1, and on (0, 1) the line is above the parabola (at x = ½, ½ > ¼). The axis is y = −1, which lies below the whole region, so the **further** boundary from the axis is the upper curve: R = x − (−1) = x + 1, and the nearer is r = x² + 1. V = π∫₀¹[(x + 1)² − (x² + 1)²]dx = π∫₀¹[(x² + 2x + 1) − (x⁴ + 2x² + 1)]dx = π∫₀¹(2x − x² − x⁴)dx = π[x² − x³/3 − x⁵/5]₀¹ = π(1 − 1/3 − 1/5) = π(15 − 5 − 3)/15 = **7π/15.** About the x-axis the same region gives 2π/15; the shift makes the solid larger because moving the axis a unit further away increases both radii by 1, and since R² − r² = (R − r)(R + r) with R − r unchanged and R + r increased by 2, every annulus gains area — the solid becomes a fatter ring around a wider hole. (Note that it is not "2π/15 plus a constant": the increase depends on x through R + r.) — *Concept: rotating about y = k shifts every radius by −k; the difference of squares grows because the sum of the radii grows.*
15. **(i) 81π/2, (ii) 972π/5, (iii) 648π/5.** The region is bounded above by y = √x, below by y = 0, on the right by x = 9; its corner is (9, 3).
**(i) About the x-axis — discs, in dx.** The axis is horizontal, so slices perpendicular to it stack in x; the region reaches the axis at every x, so there is no hole and the cross-section is a full disc of radius √x. V = π∫₀⁹(√x)²dx = π∫₀⁹x dx = π[x²/2]₀⁹ = **81π/2.**
**(ii) About the y-axis — shells, in dx** (washers in dy also work). The boundary is given as y = √x, so shells need no inversion: radius x, height √x, thickness dx. V = 2π∫₀⁹x^{3/2}dx = 2π[(2/5)x^{5/2}]₀⁹ = 2π(2/5)(243) = **972π/5.** *Check by washers in dy:* at height y (0 ≤ y ≤ 3) the solid runs from x = y² out to x = 9, so V = π∫₀³(81 − y⁴)dy = π(243 − 243/5) = 972π/5 ✓.
**(iii) About the line x = 9 — shells, in dx.** The axis is vertical and the region lies to its left, so the shell radius is the distance 9 − x, the height is √x, and x runs 0 to 9. V = 2π∫₀⁹(9 − x)√x dx = 2π∫₀⁹(9x^{1/2} − x^{3/2})dx = 2π[6x^{3/2} − (2/5)x^{5/2}]₀⁹ = 2π[6(27) − (2/5)(243)] = 2π[162 − 486/5] = 2π(324/5) = **648π/5.** *Check by discs in dy:* the horizontal cut at height y is a full disc of radius 9 − y² (the region touches the axis x = 9 along its right edge, so there is no hole), giving π∫₀³(9 − y²)²dy = π∫₀³(81 − 18y² + y⁴)dy = π(243 − 162 + 243/5) = 648π/5 ✓. — *Concept: one region, three axes, three different solids; the axis fixes the radius and, with the slicing direction, the variable of integration.*
