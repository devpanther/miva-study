## Answers

**1. B.** Multiply first, then add: 2(2) + 3 = 4 + 3 = 7. A adds before multiplying, giving 2 + 3. C brackets the whole sum, 2(2 + 3) = 10. D stops at 2x and forgets the + 3.

**2. C.** Square first, then subtract: (3)² − 4 = 9 − 4 = 5. A uses 2x instead of x², giving 6 − 4. B adds 4 rather than subtracting it. D subtracts before squaring, (3 − 4)² = 1 — a different function.

**3. D.** The denominator must not be zero: x² + 5 ≠ 0, so x² ≠ −5, and no real number squares to a negative, so nothing is excluded. A solves x² + 5 = 0 as if it were x + 5 = 0. B treats x² = −5 as having roots ±√5, ignoring the sign. C invents an inequality; a denominator restriction is an exclusion, not a half-line.

**4. A.** The range is the set the arrows actually reach, {1, 4, 9, 16, 25}. B is the domain. C is the codomain — it includes the three unreached values. D is what the codomain has left over, which belongs to no named set here.

**5. B.** Solving y = 2x − 9 for x gives x = (y + 9)/2, a legal real number for every real y, so every output is attainable. A and C mistake the constant −9 for a boundary of the range, as if the function were bounded. D imports a rational-function exclusion into a linear one.

**6. C.** |x − 3| ≥ 0, so −|x − 3| ≤ 0, so 2 − |x − 3| ≤ 2. A forgets that multiplying by −1 reverses the inequality, giving y ≥ 2. B mishandles the sign to reach −2. D reads the 3 out of |x − 3| and treats it as the bound, but 3 is an x-value, not a y-value.

**7. A.** Domain: x + 2 ≥ 0, so x ≥ −2, giving [−2, ∞). Range: √(x + 2) ≥ 0, so √(x + 2) − 8 ≥ −8, giving [−8, ∞). B drops both signs, reading x − 2 and + 8. C gives the range of the square root alone and forgets the − 8. D forgets that the square root restricts the domain at all.

**8. D.** Let y = 3x − 7, switch to x = 3y − 7, isolate: 3y = x + 7, y = (x + 7)/3. A loses the sign when moving the −7 across. B is the reciprocal 1/f(x), not the inverse. C reverses the operations but forgets to divide by 3.

**9. A.** f ∘ g = f[g(x)] = f[x²] = 5(x²) − 4 = 5x² − 4. B and C are g ∘ f — the wrong order, and C is its expanded form. D multiplies f and g instead of composing them.

**10. C.** g ∘ f = g[f(x)] = (5x − 4)² = (5x − 4)(5x − 4) = 25x² − 20x − 20x + 16 = 25x² − 40x + 16. A is f ∘ g, the other order. B squares each term separately and loses both cross terms. D collects only one of the two −20x terms.

**11. B.** Substituting gives 0 + 2 = 2, 1 + 2 = 3, 2 + 2 = 4. The printed 2, 1, 0 is the table of 2 − x, which agrees with x + 2 only at x = 0 — which is why the slip survived. A and C accept a wrong table. D is false: x + 2 has gradient +1 and increases.

**12. D.** Nesting means containment in one direction only: functions are relations that satisfy an extra condition (one output per input). A reverses the containment. B ignores the drawing entirely. C contradicts it — nothing sits in the inner circle and outside the outer one.

**13.** Slide 25: "A function is a mathematical relation that assigns exactly one output value to each input value." Slide 9 draws functions as a circle **inside** relations, where relations are "all sets of ordered pairs" and functions are "sets of ordered pairs where each input has only one output". Because a function is defined as a relation with an extra condition imposed on it, every function automatically qualifies as a relation — that is the inner circle sitting inside the outer one. The converse fails because the extra condition is a real restriction: a set of pairs such as {(1, 2), (1, 4)} is a perfectly good relation but sends the input 1 to two different outputs, so it lives in the outer ring and not the inner circle. Note that repeated *outputs* break nothing — {(1, 2), (2, 2)} is still a function.

**14.** Correct table for f(x) = x + 2: at x = 0, y = 0 + 2 = 2; at x = 1, y = 1 + 2 = 3; at x = 2, y = 2 + 2 = 4. The points to plot are (0, 2), (1, 3) and (2, 4), lying on a line of gradient 1 through (0, 2). The printed values 2, 1, 0 are the outputs of **f(x) = 2 − x**, a decreasing line through the same point (0, 2) — the two functions agree only at x = 0, which is why the error is easy to miss. The slide is misprinted; the correct answer is 2, 3, 4.

**15.** *Domain.* A square root needs a non-negative quantity underneath, so x + 2 ≥ 0, giving x ≥ −2, i.e. **D = [−2, ∞)**. The bracket is square because x = −2 is legal: h(−2) = √0 − 8 = −8. *Range.* Build upward from the root: √(x + 2) ≥ 0, then subtract 8 from both sides to get √(x + 2) − 8 ≥ 0 − 8, i.e. y ≥ −8, so **R = [−8, ∞)**, again with a square bracket because −8 is attained at x = −2. *The inequality step.* In Range Example 3 the reversing step is going from |x − 3| ≥ 0 to −|x − 3| ≤ 0: the whole expression is multiplied by −1, and multiplying an inequality by a negative number flips its direction. No step here does that — subtracting 8 is adding a constant to both sides, which shifts both sides equally and leaves the direction untouched. That is why Example 3's range opens downward, (−∞, 2], while this one opens upward, [−8, ∞).
