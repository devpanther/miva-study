## Multiple choice (12)

**1.** Which statement correctly distinguishes the Internet from the World Wide Web?
a) They are the same thing with different names
b) The Internet is an application built on the World Wide Web
c) The Internet is the global infrastructure of interconnected networks; the Web is an application built on top of it
d) The World Wide Web is hardware and the Internet is software

**2.** What was ARPANET originally developed for?
a) E-commerce  b) Military purposes, later expanded to academic use  c) Entertainment streaming  d) Personal blogging

**3.** Who introduced the World Wide Web, and in what year?
a) Bill Gates, 1995  b) Tim Berners-Lee, 1989  c) Steve Jobs, 1989  d) Tim Berners-Lee, 1999

**4.** What feature makes navigation of the Web seamless?
a) Cookies  b) Hyperlinks  c) Firewalls  d) Load balancers

**5.** In web development, which pairing is correct?
a) Front-end = server logic; back-end = user interface
b) Front-end = user interface; back-end = server logic
c) Front-end = database only; back-end = design only
d) Front-end and back-end mean the same thing

**6.** What is the correct order of the client-server request cycle?
a) Server sends response → browser sends request → user enters URL → browser renders
b) User enters URL or clicks link → browser sends HTTP request → server processes and sends HTTP response → browser renders and displays
c) Browser renders → user enters URL → server processes → HTTP request sent
d) Server processes request → user enters URL → browser sends request → browser renders

**7.** Which of these is a database server, not a web server?
a) Apache  b) Nginx  c) MongoDB  d) Microsoft IIS

**8.** Node.js is an example of which server type?
a) Web server  b) Application server  c) Proxy server  d) Database server

**9.** Which tool is a lightweight text editor rather than a full IDE?
a) JetBrains WebStorm  b) Microsoft Visual Studio  c) Visual Studio Code  d) Eclipse

**10.** What is the main role of a proxy server?
a) Storing structured data in tables
b) Acting as an intermediary for caching, load balancing, and security filtering
c) Rendering HTML, CSS, and JavaScript
d) Compiling source code

**11.** Which of the following is NOT one of the three advantages of client-server architecture named in the lecture?
a) Scalability  b) Centralised data management  c) Separation of concerns  d) Automatic code generation

**12.** Which of the following is the correct core web technology triad?
a) HTML, SQL, Python  b) HTML, CSS, JavaScript  c) URL, HTTP, FTP  d) CSS, Node.js, MongoDB

## Short answer (3)

**13.** State precisely the difference between the Internet and the World Wide Web, one sentence each.

**14.** List the functions of a web server as covered in the lecture.

**15.** Name the four roles or benefits of version control systems in web development.

## Answer key

**1. c** — *Internet vs Web*: infrastructure versus application built on it.
**2. b** — *ARPANET origin*: military first, then academic.
**3. b** — *history of the Web*: Tim Berners-Lee, 1989.
**4. b** — *hyperlinks* link pages and make navigation seamless.
**5. b** — *front-end vs back-end*: user interface versus server logic and databases.
**6. b** — *the four-step client-server request cycle* in order.
**7. c** — *server types*: MongoDB is a database server; Apache, Nginx and IIS are web servers.
**8. b** — *server types*: Node.js is the named example of an application server.
**9. c** — *text editor vs IDE*: VS Code is a text editor; WebStorm, Visual Studio and Eclipse are IDEs.
**10. b** — *proxy servers*: intermediaries for caching, load balancing and security filtering.
**11. d** — *advantages of client-server architecture*: scalability, centralised data management, separation of concerns.
**12. b** — *core web technologies*: HTML, CSS, JavaScript.
**13.** *Internet vs Web*: the Internet is the global infrastructure of interconnected computers and networks, originating from ARPANET; the World Wide Web is an application — a system of interconnected pages accessed via hyperlinks — built on top of it, introduced by Tim Berners-Lee in 1989.
**14.** *Server functions*: request handling, data storage, dynamic content generation, security (HTTPS), and load balancing.
**15.** *Roles of VCS*: code collaboration, version history, branching and merging, and code backup.
