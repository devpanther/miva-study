# Thursday — MTH_102 nightly check

*This session worked the same Week 1 material as problems rather than ideas: given a function, produce the answer. It drilled reading a question to see which restriction is in play and stacking several at once (even root plus denominator, root plus quotient), completing the square to get a range, solving `y = f(x)` for `x` to get the range of a rational, running the swap-and-solve algorithm for an inverse through the messy rational case, building composites in the right order and evaluating them at a number, and applying the two-part domain rule to a composite. It also drilled the habits around the algebra — checking an inverse by composing back to `x`, choosing between completing the square and solving for `x` before starting, and recognising the standard wrong routes: dropping the denominator condition, taking a reciprocal instead of an inverse, quoting the vertex's `x`-coordinate as the range, composing in the wrong order, and simplifying a composite and then forgetting the inner function's own domain.*

*Sit cold, notes closed, about 15 minutes. Score out of 12.*

**1.** The domain of `f(x) = √(x + 4)/(x − 1)` is:
a) `[−4, ∞)`
b) `[−4, 1) ∪ (1, ∞)`
c) `(−4, 1) ∪ (1, ∞)`
d) `(−∞, −4] ∪ (1, ∞)`

**2.** The range of `f(x) = x² − 6x + 11` is:
a) `[11, ∞)`
b) `(−∞, 2]`
c) `[3, ∞)`
d) `[2, ∞)`

**3.** If `f(x) = (3x − 2)/(x + 4)`, then `f⁻¹(x)` equals:
a) `(4x + 2)/(3 − x)`
b) `(4x + 2)/(x − 3)`
c) `(x + 4)/(3x − 2)`
d) `(3x + 2)/(x − 4)`

**4.** With `f(x) = 1/(x − 2)` and `g(x) = √x`, the domain of `f∘g` is:

c) `[0, 4) ∪ (4, ∞)`
d) `(0, ∞)`

**5.** If `f(x) = 2x − 1` and `g(x) = x² + x`, then `(g∘f)(3)` equals:

d) 30

c) apply the vertical line test to `g`

**7.** The range of `f(x) = (2x + 1)/(x − 3)` is:

**8.** With `f(x) = √(x − 1)` and `g(x) = x − 5`, the domain of `f/g` is:

**9. (explain why)** A student gives the domain of `h(x) = √(x² − 9)` as `x ≥ 3`. Name the step at which that method went wrong, and give the correct domain with the reasoning that produces it.

**10. (explain why)** Before touching the algebra, you must choose between completing the square and solving `y = f(x)` for `x` when a question asks for a range. Say what feature of the function tells you which to pick, and state which you would use for `f(x) = (x + 2)/(x − 4)` and why.

**11. (explain why)** You have just produced a candidate `f⁻¹` for `f(x) = (x − 1)/(x + 2)`. Describe the check you would run, state exactly what the check must return, and say what a failure would tell you about where the error is.

**12. (explain why)** For `f(x) = 1/x` and `g(x) = x − 3`, explain why `f∘g` and `g∘f` have different domains, naming the excluded value in each case.
