## Answers

**1. A** — 2(−4) + 3 = −8 + 3 = −5. Option 2 subtracts the constant instead of adding it, computing −8 − 3. Option 3 drops the minus sign on the input and evaluates f(4) = 11. Option 4 brackets the whole thing as 2(−4 + 3) = −2, which is the same order-of-operations slip that turns f(2) = 7 into 10 on her slide.

**2. B** — (−3)² = 9, so f(−3) = 9 − 4 = 5 — the same value as f(3), because squaring destroys the sign. Option 1 treats (−3)² as −9. Option 3 uses 2x in place of x², giving −6 − 4. Option 4 subtracts before squaring, (−3 − 4)² = 49, which is a different function altogether.

**3. C** — Set x² − 9 ≠ 0, so x² ≠ 9, so x ≠ 3 and x ≠ −3 — both roots must go, because both make the denominator zero. Option 1 copies the answer of her Example 2 without redoing the algebra; there the equation had no real root, here it has two. Option 2 keeps only the positive root and forgets that (−3)² is also 9. Option 4 solves x² = 9 as though the square were not there. Note that she only ever displays the no-exclusion case on the surviving slides, so this is her rule applied where it actually bites.

**4. D** — Set y = 5 − 4x, then 4x = 5 − y and x = (5 − y)/4. That is a legal real number for every real y — nothing is divided by zero and no root is taken — so every output is attainable and the range is all of ℝ. Options 1 and 2 read the constant 5 as a ceiling or a floor, which happens with absolute values and squares but never with a straight line. Option 3 imports an exclusion from rational functions into a linear one. A line with non-zero gradient always has range (−∞, ∞).

**5. A** — |x + 1| ≥ 0, and subtracting 4 from both sides gives |x + 1| − 4 ≥ −4, so y ≥ −4 and the range is [−4, ∞), with the bracket square because y = −4 is attained at x = −1. Option 2 reverses the inequality out of habit, but nothing here was multiplied by a negative — that reversal belongs to her Example 3, where the absolute value itself carried a minus sign. Option 3 keeps the direction but loses the sign of the constant. Option 4 forgets that an absolute value is bounded below and drags the range down to −∞.

**6. B** — Let y = 4x + 9; switch to x = 4y + 9; isolate: 4y = x − 9, so y = (x − 9)/4. Check it: f(2) = 17 and (17 − 9)/4 = 2. Option 1 adds the 9 instead of subtracting when moving it across the equals sign — the commonest single error in this topic. Option 3 is the reciprocal 1/f(x), not the inverse. Option 4 reverses the operations in the right order but never divides by 4, so it undoes the +9 and not the ×4.

**7. C** — g ∘ f means f runs first: f(2) = 5(2) − 4 = 6, then g(6) = 6² = 36. It agrees with the expanded form 25x² − 40x + 16 at x = 2: 100 − 80 + 16 = 36. Option 1 is (f ∘ g)(2) = 5(4) − 4 = 16, the other order, and its difference from 36 is the whole point of her two examples. Option 2 comes from the wrong expansion 25x² + 16 at x = 2. Option 4 applies f and then forgets to square.

**8. D** — Under the root: x − 5 ≥ 0, so x ≥ 5 and D = [5, ∞). For the range: √(x − 5) ≥ 0, so √(x − 5) + 3 ≥ 3 and R = [3, ∞), both brackets square because x = 5 gives h(5) = 3 exactly. Option 1 gets the sign wrong when solving x − 5 ≥ 0. Option 2 finds the domain but forgets that the + 3 lifts every output by three. Option 3 forgets that a square root restricts the domain at all, which would only be true for an odd root.

**9.** A good answer treats the two parts by different methods, as she does. Domain: the quantity under a square root cannot be negative, so x + 2 ≥ 0 and x ≥ −2, giving D = [−2, ∞). Range: build upward from √(x + 2) ≥ 0, subtract 8 from both sides to get √(x + 2) − 8 ≥ 0 − 8, hence y ≥ −8 and R = [−8, ∞). On the brackets: both are square at the finite end because both endpoints are attained — x = −2 is a legal input and h(−2) = √0 − 8 = −8 is the actual smallest output — while ∞ always takes a round bracket because it is never reached. Credit an explicit note that subtracting 8 does not reverse the inequality, since nothing was multiplied by a negative.

**10.** A good answer writes f ∘ g = f[g(x)] = f[x²] = 5(x²) − 4 = 5x² − 4, with the brackets round x² so the 5 multiplies the whole square. Then g ∘ f = g[f(x)] = g[5x − 4] = (5x − 4)², expanded as (5x − 4)(5x − 4) = 25x² − 20x − 20x + 16 = 25x² − 40x + 16, showing both middle terms before collecting them — this is where the marks are, and the shortcut 25x² + 16 is the error the long expansion prevents. At x = 3: f ∘ g gives 5(9) − 4 = 41, while g ∘ f gives 25(9) − 120 + 16 = 121, which is also (15 − 4)² = 11² = 121. The two differ, so f ∘ g is not g ∘ f.

**11.** A good answer labels the steps. Let: y = 3x − 7. Switch x with y: x = 3y − 7. Isolate the y variable: 3y = x + 7, then y = (x + 7)/3. So f⁻¹(x) = (x + 7)/3 — and it should write the argument, since her slide writes only f⁻¹ = (x + 7)/3. Verification: take any input, say x = 4, so f(4) = 3(4) − 7 = 5; feeding 5 back gives f⁻¹(5) = (5 + 7)/3 = 4, the original input, which is what an inverse is supposed to do. Credit an answer that also notes the reciprocal 1/(3x − 7) would have returned 1/5 here, not 4, and is therefore a different object.

**12.** A good answer substitutes each value into the actual rule: x = 0 gives 2, x = 1 gives 3, x = 2 gives 4, x = 3 gives 5, x = 4 gives 6. The points are (0, 2), (1, 3), (2, 4), (3, 5) and (4, 6). Comparing consecutive points, y rises by 1 each time x rises by 1, so the gradient is 1, and the value at x = 0 is 2, so the y-intercept is 2 — both read straight off the rule y = x + 2. It should state plainly that the slide's printed values 2, 1, 0 are the outputs of 2 − x, a line of gradient −1 through the same intercept, and that the two agree only at x = 0.
