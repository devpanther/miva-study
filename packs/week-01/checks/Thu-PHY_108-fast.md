# Thursday — PHY_108 fast-hour check

*The straight-line equation, linearising the pendulum, error types, percentage difference and the best-fit rule.*
*Five questions, straight after the fast hour. Recall only. Score out of 5.*

**1.** In y = mx + c, what does c represent?
A. The gradient
B. The y-intercept
C. The x-intercept
D. The dependent variable

**2.** To linearise the simple pendulum, what is plotted against L?
A. T squared
B. T
C. ln T
D. log L

**3.** Which error scatters both ways and shrinks when readings are averaged?
A. Systematic error
B. Zero error
C. Absolute error
D. Random error

**4.** Which quantity keeps its sign, negative when the observed value is lower?
A. Absolute error
B. Relative error
C. Percentage difference
D. Percentage error

**5.** The gradient triangle must be read from two points lying where?
A. On two raw plotted data points
B. On the drawn best-fit line
C. On the two axes
D. At the origin and one data point

## Answers

**1. B** — c is the y-intercept, the value of y when x is zero. The gradient is m, and the x-intercept is minus c over m, found by setting y to zero.

**2. A** — Squaring gives T squared equal to (4 pi squared over g) times L, so T squared against L is a straight line through the origin. Logs are the tool for exponential decay and power laws, not for this one.

**3. D** — Random error comes from unpredictable factors and averages out over repeats. Systematic error, such as an instrument zero error, has the same size and direction every time, so repeating never removes it.

**4. C** — Percentage difference divides by a reference value and keeps its sign. Percentage error divides by the true value and is quoted as a magnitude; absolute and relative error are magnitudes too.

**5. B** — Take two widely separated points that lie on the drawn best-fit line, so all readings contribute. Raw data points carry their own scatter, and the origin is only usable if the line actually passes through it.
