# Tuesday — CSC_106 fast-hour check

*Web origins, Internet versus Web, the client-server request cycle, server types and developer tools.*
*Five questions, straight after the fast hour. Recall only. Score out of 5.*

**1.** Who introduced the World Wide Web, and in which year?
A. Sir Tim Berners-Lee, 1989
B. Sir Tim Berners-Lee, 1969
C. The ARPANET team, 1989
D. The ARPANET team, 1991

**2.** If the Internet is the infrastructure, what is the World Wide Web?
A. The protocol browsers use to fetch pages
B. An application of hyperlinked pages running on it
C. The global network of interconnected devices
D. The system that maps addresses to servers

**3.** After the user enters a URL, what does the browser send next?
A. An HTTP response
B. A rendered page
C. An HTTP request
D. A database query

**4.** Node.js is given as the example of which type of server?
A. Web server
B. Database server
C. Proxy server
D. Application server

**5.** Which trio names the three categories of web development tools?
A. Text editors and IDEs, browser developer tools, version control
B. Browsers, web servers, database servers
C. HTML, CSS, JavaScript
D. Editors, compilers, debuggers

## Answers

**1. A** — Berners-Lee introduced the Web in 1989. ARPANET is the military network the Internet itself grew from, and 1969 belongs to that earlier story, not to the Web.

**2. B** — The Web is one application built on the Internet: interconnected pages joined by hyperlinks. The protocol is HTTP, and the network of interconnected devices is the Internet itself.

**3. C** — The browser sends an HTTP request; the server replies with the HTTP response, and only then does the browser render. The database query happens on the server side, not from the browser.

**4. D** — Node.js is the named application server, which executes application code. Apache, Nginx and IIS are the web servers; MySQL, PostgreSQL and MongoDB the database servers; proxies do caching, load balancing and security.

**5. A** — The week names text editors and IDEs, browser developer tools, and version control systems. The others are real course lists but of servers, of core languages, or of tools the course never groups that way.
