# COS_102 — Week 1 retention set

*Introduction to Problem Solving · sit this seven days after the week's sessions, notes closed. 12 MCQ + 3 short answer.*

**1.** Why does solving problems with a computer require a *systematic* approach?

a) Because computers are faster than humans and speed magnifies any disorder.
b) Because the computer itself processes information in a systematic manner.
c) Because high-level languages will not compile unsystematic code.
d) Because abstract problems, unlike real-world ones, have no natural order.

**2.** "How many students in the cohort scored above 70?" is which type of computational problem?

a) A counting problem.
b) A search problem.
c) A decision problem.
d) An optimization problem.

**3.** An algorithm is defined as a procedure of steps used to solve a given problem. What must be true of the steps?

a) They must be written in a high-level language such as C, C# or Java.
b) They must be few enough to fit on a single flowchart page.
c) They must be ordered, unambiguous and complete.
d) They must be numbered, testable and documented.

**4.** Which statement about pseudocode and flowcharts is correct?

a) A flowchart is textual and a pseudocode is graphical.
b) A flowchart can be executed directly; pseudocode cannot.
c) Pseudocode represents the algorithm; a flowchart represents the finished source code.
d) Both represent the same algorithm — one textually, the other graphically.

**5.** What is the correct order of the four steps to problem-solving?

a) Create a plan → understand the problem → evaluate and refactor → carry out the plan.
b) Understand the problem → create a step-by-step plan → carry out the plan → evaluate and refactor.
c) Understand the problem → carry out the plan → create a step-by-step plan → evaluate and refactor.
d) Create a plan → carry out the plan → understand the problem → evaluate and refactor.

**6.** Carrying out the solution plan was said to involve four activities. Which set?

a) Coding; compilation and execution; debugging and testing; program documentation.
b) Analysis; design; implementation; maintenance.
c) Decomposition; algorithm; pseudocode; flowchart.
d) Input; processing; output; storage.

**7.** A compiler converts a high-level language into what?

a) Machine code, directly.
b) Pseudocode that a programmer then reviews.
c) Assembly language, which an assembler then converts.
d) Source code, which the CPU then executes.

**8.** Why does nobody write large programs directly in machine code, even though it is the only thing the computer understands?

a) Because machine code cannot express decisions or loops.
b) Because modern CPUs no longer accept machine code as input.
c) Because machine code is a high-level language and therefore too slow.
d) Because even small programs run to thousands of 0s and 1s and are very hard to write and troubleshoot.

**9.** Which set names the three error types identified this week?

a) Input, processing and output errors.
b) Syntax, logical and run time errors.
c) User, programmer and compiler errors.
d) Decision, search and counting errors.

**10.** A document telling a maintenance programmer how the reorder-point module is structured so it can be upgraded is which type of documentation?

a) User documentation.
b) Testing documentation.
c) Programmer documentation.
d) Refactoring documentation.

**11.** Refactoring a working solution is intended to do what?

a) Improve its efficiency, structure and design without changing its function.
b) Extend its function so it handles cases the first version could not.
c) Remove the logical errors that debugging failed to find.
d) Convert its pseudocode into a flowchart before coding begins.

**12.** With the help of input devices, a computer will accept as input:

a) Only numbers and letters, since everything else must be typed as text first.
b) Only data that has already been stored on an external memory device.
c) Anything a human can perceive, whether it can be digitised or not.
d) Anything that can be converted into a digital form — including pictures, sound waves and Wi-Fi signals.

## Short answer

**13.** Name the four steps to problem-solving in order, and give in one clause the job each step does.

**14.** Distinguish an algorithm, a pseudocode and a flowchart. For each, say what it is and what it is used for.

**15.** Name the four types of computational problem, and give a one-line example of each drawn from a school or shop setting.

## Answers

**1. b** — the lesson's stated reason: the computer processes information systematically, so the solution handed to it must be systematic too.
**2. a** — the solution is the *number* of values with a particular property, which is the definition of a counting problem.
**3. c** — ordered, unambiguous and complete, so the algorithm can easily be converted into a program.
**4. d** — pseudocode is the textual and the flowchart the graphical representation of the same algorithm.
**5. b** — understand, plan, carry out, evaluate and refactor; you cannot plan what you have not understood.
**6. a** — the four activities listed under "what does carrying out the solution plan entail".
**7. c** — compilers produce assembly language; only the interpreter goes straight to machine code.
**8. d** — machine code is what the computer understands but is very difficult to write and troubleshoot at any size.
**9. b** — syntax, logical and run time are the three named error types.
**10. c** — programmer documentation carries the technical detail needed to upgrade and maintain the program.
**11. a** — refactoring never changes the function; it improves efficiency, structure and design.
**12. d** — computers accept anything convertible to digital form, which is why retinal scans and Wi-Fi signals are on the list.
**13.** Understand the problem (establish inputs, processes, output); create a step-by-step plan (decompose, write the algorithm as pseudocode and flowchart); carry out the plan (code, compile and execute, debug and test, document); evaluate and refactor (improve efficiency and structure without changing function).
**14.** The algorithm is the procedure of ordered, unambiguous, complete steps that solves the problem; the pseudocode is its textual representation, written to convert easily into programming statements but not compilable; the flowchart is its graphical representation, showing the sequence of operations using symbols for start, stop, input, process, merge and decision.
**15.** Decision — "is any product below its reorder point?" (YES/NO); Search — "which students scored exactly 45?" (values with a property); Optimization — "which stock mix gives the lowest carrying cost within budget?" (the best one is accepted); Counting — "how many products sold out last week?" (the number of values with a property).
