# Tuesday — CSC_106 fast-hour check

*Transfer protocols, markup languages, mail protocols, the DNS hierarchy and REST's verb-to-CRUD mapping.*
*Five questions, straight after the fast hour. Recall only. Score out of 5.*

**1.** Which protocol is the secure extension of FTP?
A. HTTPS
B. SFTP
C. SMTP
D. DNSSEC

**2.** Which markup language stores structured data using user-defined tags?
A. HTML
B. SVG
C. XML
D. MathML

**3.** Which mail protocol keeps messages on the server and syncs across devices?
A. POP3
B. SMTP
C. MIME
D. IMAP

**4.** In admin.example.com, which label is the top-level domain?
A. com
B. example
C. admin
D. www

**5.** In REST, which HTTP method maps to Create in CRUD?
A. GET
B. POST
C. PUT
D. DELETE

## Answers

**1. B** — SFTP adds encryption and strong authentication to file transfer. HTTPS secures HTTP rather than FTP, SMTP sends mail, and DNSSEC signs DNS data.

**2. C** — XML stores and exchanges structured data with tags the author defines. HTML has a fixed tag set for structuring web content, SVG draws vector graphics, and MathML writes mathematical notation.

**3. D** — IMAP leaves mail on the server and synchronises actions across devices. POP3 downloads to one device for offline access, SMTP is outbound only, and MIME defines message format, not transport.

**4. A** — The rightmost label, com, is the TLD; example is the second-level domain and admin the subdomain. The hierarchy runs root, then TLD, then second-level, then subdomain.

**5. B** — POST creates a resource. GET retrieves (Read), PUT updates, and DELETE removes.
