Client-Server Architecture

delivery process across dierent domains.

Domain Name System (DNS)
The Domain Name System (DNS) is a fundamental component of the internet that
converts human-readable domain names (e.g., www.example.com) into IP
addresses (e.g., 192.0.2.1).
It plays a crucial role in enabling internet communication and simplifying the

services.

Domain Name Resolution
Domain name resolution is the process of translating a human-readable domain
name into an IP address.
It allows computers to locate and connect to servers on the internet using
easy-to-remember domain names.
     Introduction to Web Technologies

Name to IP Address Mapping: DNS maps domain names to IP addresses, enabling
computers to locate web servers, email servers, and other network resources.

address).

contains top-level domains (TLDs) like .com, .org, and .net.

Web Application Security
In this increasingly digitised world, web applications have become integral to our daily lives,
ranging from online shopping and social networking to banking and healthcare services.
However, with the convenience they oer, web applications also bring signiﬁcant security
challenges.
Web application security is the practice of protecting web applications from threats that can
compromise the conﬁdentiality, integrity, or availability of data.
These threats can come from various sources, including malicious users, aackers, and
vulnerabilities within the application itself.
   Introduction to Web Technologies


Terminologies IN Web Application Security
Web Application: A web application is a software program that operates on a web server and
interacts with users through a web browser. Examples include online banking portals,
e-commerce websites, and social media platforms.

Vulnerability: A vulnerability is a weakness in a web application’s design, implementation, or
conﬁguration that can be exploited by aackers to compromise its security.

Threat: A threat is a potential danger or harm to a web application’s security. Threats can
include SQL injection, cross-site scripting (XSS), and distributed denial of service (DDoS)
aacks.
     Introduction to Web Technologies


Web Application Vulnerabilities
SQL Injection (SQLi): SQL injection occurs when an aacker inserts malicious SQL code into
user inputs, manipulating the application’s database. For example, entering 'OR 1=1--' in a
login form may grant unauthorized access.
Cross-Site Scripting (XSS): XSS vulnerabilities enable aackers to inject malicious scripts
into web pages viewed by other users. This can lead to data theft or session hijacking. An
example is embedding malicious JavaScript in a comment section.
Cross-Site Request Forgery (CSRF): CSRF aacks trick users into performing unwanted
actions without their consent when authenticated on a web application. For instance, an
aacker could send a malicious link that changes a user’s email address on their proﬁle..
Injection Aacks: Besides SQL injection, other injection aacks like Command Injection
and XML Injection can exploit applications that process user-supplied data without proper
validation.
Security Misconﬁgurations: These occur when developers overlook security seings and
leave sensitive information exposed. An example is leaving database credentials in plaintext
conﬁguration ﬁles.
     Introduction to Web Technologies


Web Application Security: Best Practices
Input Validation: Always validate and sanitise user inputs to prevent injection aacks. Use
parameterised queries for database interactions to prevent SQL injection.
Output Encoding: Encode output to prevent XSS aacks. Tools like Content Security Policy
(CSP) can help mitigate XSS risks.
Authentication and Authorization: Implement strong authentication mechanisms and limit
user privileges based on roles and permissions. Two-factor authentication (2FA) adds an
extra layer of security.
Session Management: Securely manage user sessions and use unique tokens to prevent
CSRF aacks. Consider implementing session expiration policies.
Security Headers: Utilise security headers like HTTP Strict Transport Security (HSTS) and
X-Content-Type-Options to bolster application security.
Regular Updates: Keep all components of your web application, including libraries and
frameworks, up to date to patch known vulnerabilities.
Security Testing: Regularly conduct security testing, including vulnerability scanning,
penetration testing, and code reviews, to identify and remediate security ﬂaws.

WebAssembly, often abbreviated as Wasm, is a binary instruction format designed for
web browsers. It allows high-performance execution of code on web pages.

Traditional web technologies like JavaScript have limitations in terms of performance.
WebAssembly aims to address these limitations by providing a faster and more eicient
way to run code in web browsers.
WebAssembly code is compiled from other languages, like C++, Rust, or TypeScript,
into a binary format that can be executed directly by the browser. This makes it highly
eicient.

computationally-intensive tasks like gaming, simulations, and video editing. Example: Running a

compatibility across dierent platforms. Example: Developing a web app that works seamlessly
on both desktop and mobile devices.
Security: It runs in a sandboxed environment, providing enhanced security compared to
traditional JavaScript. Example: Running untrusted code safely within a web application.

Serverless Architecture
Serverless architecture is a cloud computing paradigm where the cloud provider manages
the infrastructure, allowing developers to focus solely on writing code.

Key Concepts of Serverless Architecture include;

Functions as a Service (FaaS): The core of serverless architecture, where code is executed
in response to events.

Event-Driven: Serverless applications are event-driven, responding to events such as HTTP
requests, database changes, or ﬁle uploads.

Stateless: Serverless functions are stateless, meaning they don’t maintain server-speciﬁc
state between invocations.

Web Accessibility and Inclusivity
The web is an integral part of our lives, providing information, services, and opportunities.
However, not everyone can access and use the web equally.
Web accessibility refers to the practice of ensuring that websites, web applications, and web
content are usable by people with disabilities.
Inclusivity goes beyond accessibility and encompasses designing and developing web
technologies to be inclusive of all users, regardless of their abilities or disabilities.
Disabilities: Disabilities can include visual, auditory, motor, cognitive, or other impairments that
aect a person’s ability to access web content.
WCAG (Web Content Accessibility Guidelines): WCAG provides a set of guidelines and
success criteria for creating accessible web content.
A11Y (Accessibility): "A11Y" is a numeronym for "accessibility," highlighting the importance of
accessibility in web development.
     Introduction to Web Technologies


Web Accessibility Principles
Perceivable: Information and user interface components must be presented in a way that can
be perceived by all users, including those with disabilities. Example: Providing alternative text for
images for screen reader users.
Operable: Users must be able to navigate and interact with the website using various input
methods, including keyboard and voice commands. Example: Ensuring all interactive elements
are keyboard accessible.
Understandable: Web content should be clear and easy to understand for all users. Example:
Using plain language in text content.
Robust: Websites should be designed to work with current and future technologies, ensuring
longevity. Example: Using semantic HTML to structure content.

Screen Readers: Software that converts text and visual content into speech or Braille for blind
and visually impaired users.
Voice Recognition Software: Allows users to navigate and interact with websites using voice
commands.
Keyboard Navigation: Ensuring all interactive elements can be accessed and operated using a
keyboard.
Closed Captions and Subtitles: Providing textual alternatives for audio content, beneﬁting deaf
and hard-of-hearing users.
Web Accessibility Tools and Technologies
Colour Contrast Tools: Tools that help ensure suicient contrast between text and background
colours for users with visual impairments.
