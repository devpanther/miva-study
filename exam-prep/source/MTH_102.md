Vertical Line Test
A vertical line test helps us to determine whether a
curve on a graph is a function or not.

If any vertical line intersects the graph at more
than one point, it fails the Vertical Line Test but if
every vertical line intersects the graph at most
once, it passes the Vertical Line Test.

Passing the Vertical Line Test indicates that the
graph represents a function.
Failing the test means the graph does not
represent a function (instead it represents a
relation) because it associates one input with
multiple outputs.
